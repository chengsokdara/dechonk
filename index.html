How it works

Three steps. Zero regret.

01

Scan

A parallel Rust walker sweeps your home folder, all drives, or anywhere you point it. Nested installs are deduplicated and junk folders are skipped before they can waste a millisecond. Every kind counts only on its own terms: Rust target folders with cargo's CACHEDIR.TAG, Go's caches at their canonical locations with Go's own markers, Gradle and Maven outputs under a real build script or pom, web build caches with their well-known files inside, and the npm, pnpm, and yarn caches at their canonical locations. Lookalikes are never touched.

02

Assess

Sizes stream in live as it walks. Sort by chonk, filter by how long nobody has touched it, and deal with the biggest offenders first.

03

Dechonk

One click sends folders past the event horizon: your OS Trash, and the only horizon in physics with a return policy. Need them gone for good? Drop them into the singularity: permanent deletion, always behind a confirmation that tells you exactly what it frees.

Safety

What Dechonk will never do

Touch your source files

Only build-artifact folders are targets: dependency folders, toolchain build caches, web build caches, and the shared Go, Gradle, Maven, npm, pnpm, and yarn caches. Your code isn't even scanned, let alone moved.

Follow symlinks into the void

Symlinks are never followed. Whatever lives outside the folder stays outside the folder.

Delete without asking

Everything stops at the event horizon first: your OS Trash, fully recoverable. The singularity (permanent delete) always asks, and always says exactly what it will free.

Phone home

No telemetry, no accounts, no network. The scanner doesn't know what the internet is.

FAQ

Questions from the event horizon

Is deleting node_modules safe?+

Yes. Your source code is never touched, and everything Dechonk removes is regenerable: dependencies come back with npm install (or pnpm/yarn/bun; Dechonk doesn't judge), Rust build output with cargo build, Go caches with go build and go mod download. They're the multi-gigabyte folders on your machine you're actually supposed to delete.

Does Dechonk delete Rust target folders?+

Yes, but carefully. A folder named target is only ever reported when cargo's own CACHEDIR.TAG marker file is inside it, which is how cargo flags its build cache. A plain folder that happens to be named target is walked past, never reported, never deleted.

Does Dechonk delete Go caches?+

Yes. Dechonk finds Go's build cache and module cache at their canonical locations, and only reports them when Go's own marker files are inside, so lookalike folders are never touched. They're shared by every Go project on this machine, and the next go build or go mod download rebuilds them.

Does Dechonk delete Gradle or Maven caches?+

Yes. Gradle's dependency cache counts only once modules-2 exists inside it, and Maven's local repository only when Maven's own artifacts sit under org/apache/maven, so unused lookalike folders are never touched. They're shared by every Gradle or Maven project on this machine, and the next gradle build or mvn package rebuilds them.

Does Dechonk delete web build caches?+

Yes. Next.js, Turborepo, Parcel, Angular, and SvelteKit caches only count when their own well-known files are inside them, so lookalike folders are never touched. The npm, pnpm, and yarn caches are found at their canonical locations; they're shared by every project on this machine, and the next npm install, pnpm install, or yarn install re-fetches everything.

Does Dechonk delete anything permanently?+

No. Folders always stop at the event horizon first (your OS Trash, fully recoverable). Dropping them into the singularity (permanent deletion) is opt-in and always behind a confirmation dialog that tells you exactly how much space it frees.

How fast is the scan?+

The walker is written in Rust and runs discovery and size enrichment in parallel. Whole-drive scans typically finish in seconds, and you watch the numbers land live while it works.

Which platforms does it support?+

macOS, Windows, and Linux. The app is built with Tauri, weighs about 4 MB, and opens instantly. Free, no account required.

Why is it called Dechonk?+

Because the internet decided oversized folders are "chonky," and we are not strong enough to fight the internet. Dechonking is the act of restoring a folder to a reasonable mass. See also: the chonk scale.
